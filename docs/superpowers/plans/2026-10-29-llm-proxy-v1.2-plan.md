# babelgate v1.2 ("One endpoint, many providers") Implementation Plan

> **For agentic workers (Devin):** Run each task in its own session with `/llm-proxy-task v1.2 <N>`. One task → one branch (`v1.2/task-<N>-<short-name>`) → one PR. Steps use checkbox (`- [ ]`) syntax. Read `AGENTS.md`, this plan's Global Constraints and Review Focus, and the spec sections each task names. Use `./scripts/check.sh quick` while iterating and `./scripts/check.sh` before pushing. Verify every write with `git diff`. (The file name keeps `llm-proxy` so the agent skills find it.)

**Goal:** One babelgate instance serves every client format on one port and routes each request to one of several configured providers by model name, with aliases, a long-context condition, fallbacks before the first byte and a merged model list.

**Architecture:** A thin routing layer in front of the unchanged adapter/stream pipeline: a `ProviderRegistry` (name → type, URL, key, per-provider options), `detectSource` (request → client format), a pure `planRoute` (model → ordered targets + reason) and an `attemptTargets` loop that encodes, sends and falls back per target. `proxy.service` is split into chat, chat-stream and models services that take these as explicit inputs.

**Tech Stack:** As v1.1 (Node ≥ 20, TypeScript 5 strict, Express 5, Zod 4, pino, vitest 3, msw 2, supertest). Added: `yaml` (eemeli/yaml, latest 2.x, zero dependencies) — Task 4 only.

**Spec:** `docs/superpowers/specs/2026-10-29-babelgate-v1.2-design.md`. Parent: `docs/superpowers/specs/2026-10-26-llm-proxy-roadmap-design.md`.

**Decided with the owner (2026-10-29), spec §6:** D1 scope (gateway + Claude Code long-context routing + v1.1 gate gaps as release gates); D2 unmatched model → default provider, no built-in prefix routing; D3 YAML for ≥ 2 providers, keys by env var name only; D4 rented-GPU Ollama gate; D5 thin routing layer; D6 `yaml` dependency.

**Prerequisite (owner):** merge the spec and this plan before Task 1.

## Global Constraints

- **No existing expected value changes** unless a task names it. Existing fixtures and contract snapshots are never edited. The only named changes are in Task 2 (retiring `SOURCE_API`, spec §3.2, §3.8).
- **Behaviour-neutral Task 1:** the full suite passes with zero test-file changes.
- **No existing default changes.** `UPSTREAM_TIMEOUT_MS` 30 000, `UPSTREAM_RETRIES` 1, `UPSTREAM_STREAM_IDLE_MS` 300 000. Per-provider `timeout_ms`/`stream_idle_ms`/`context_window` are overrides only. The only new constant is the model-list cache TTL, 60 000 ms.
- **Adapters, canonical types/schema, `stream-pipeline.ts`, `http-client.ts`, `upstream-errors.ts` do not change.** No adapter imports routing or config. No provider-pair branches anywhere.
- **Routing copy, verbatim (spec §3.3–§3.4):** `RoutePlan.reason` ∈ `"explicit" | "alias:<name>" | "rule:<n>" | "default"` (`n` = 0-based index in `routes`); hop `outcome` ∈ `ok | http_error | timeout | transport`; response headers `x-babelgate-provider`, `x-babelgate-model`, `x-babelgate-attempts`, `x-babelgate-partial: true`.
- **Fallback-eligible, exactly:** transport failure; header/connect timeout; upstream `429`, `500`, `502`, `503`, `504`, `529`. Everything else fails immediately.
- **Provider names:** `^[a-z0-9][a-z0-9_-]*$`. Model and alias names are case-sensitive.
- **Secrets:** YAML holds env var names only (`api_key_env`), never keys. Keys never appear in logs, errors, the routing table or headers.
- **Privacy:** no prompt text, completion text, tool arguments or keys in any log line. The route log line carries only the fields in spec §3.4.
- **No network in `npm test`.** Real upstreams only in `tests/live/` and `scripts/gates/`.
- **Owner-only:** the `yaml` dependency, `package.json`/`package-lock.json` changes, existing-test expected-value changes, gate runs, tagging, publishing, merging.

## Review Focus

1. **Model names with `:` and several `/`** (`ollama/qwen3-coder:30b`, `openrouter/qwen/qwen3-coder`, `qwen/qwen3-coder` with no provider `qwen`, `OLLAMA/x` with provider `ollama`). Expected: split on the first `/` only when the prefix is a registered provider name (case-sensitive); otherwise the whole string is the model. → Task 3 (`model names with colons and slashes`).
2. **Client disconnects while an attempt is failing or between hops.** `postStream` reports a client abort as a timeout `UpstreamError`. Expected: the loop checks `signal.aborted` first, stops, and tries no further target. → Task 5 (`client abort stops the fallback loop`).
3. **A fallback provider of a different type or with different options.** Expected: every attempt encodes from the original canonical request; one provider's `contextWindow` or model never leaks into the next attempt. → Task 5 (`each attempt encodes from the original canonical`).
4. **Explicit provider syntax in Gemini's URL path**, including percent-encoded slashes (`/v1beta/models/openrouter%2Fqwen%2Fqwen3-coder:generateContent`). Expected: the same resolution as a body model. → Task 3 (`gemini path model resolves like a body model`).
5. **Awkward YAML:** an empty file, a file with only `default`, CRLF line endings, a duplicate map key, an `api_key_env` variable set to `""`. Expected: a startup error naming the problem (empty/duplicate/unset), never a crash or a silently empty registry; CRLF parses normally. → Task 4 (`awkward yaml files`).

Each line is pinned by a named test in the owning task.
